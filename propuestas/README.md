# 🗂️ Propuestas

Aquí el Becario Máster deja las tareas que **quiere ejecutar por ti**, cada una con su
beneficio concreto. Tú apruebas; él ejecuta.

## Cómo funciona
- Cada ciclo de propuestas genera un archivo con fecha: `2026-06-24.md`, etc.
- Usa la estructura de [`PLANTILLA.md`](./PLANTILLA.md).
- Marca `[x] Aprobar` en las que quieras. El becario solo ejecuta lo aprobado.
- Tras ejecutar, el becario rellena el "Registro de ejecución" con el resultado.

## Para lanzar un ciclo
Dile al becario: *"Lanza el ciclo de propuestas"* (o invoca la skill `proponer-tareas`).
