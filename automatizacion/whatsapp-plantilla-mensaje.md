# 📋 Plantilla del mensaje de WhatsApp (propuestas)

Formato exacto que el Becario usa para entregarte las propuestas por WhatsApp. Pensado para
leerse de un vistazo en el móvil y aprobar respondiendo con un número.

## Mensaje de propuestas (saliente → tu móvil)

```
🧠 Becario Máster · Propuestas del {fecha}

Top {n} por impacto:

1️⃣ {título corto}
   💡 Beneficio: {beneficio concreto}
2️⃣ {título corto}
   💡 Beneficio: {beneficio concreto}
3️⃣ {título corto}
   💡 Beneficio: {beneficio concreto}

Aprueba respondiendo, p.ej.: "1 sí, 3 sí"
(o "todo sí" / "todo no"). Detalle completo en el repo.
```

## Tu respuesta (entrante ← tu móvil)

Formatos que el Becario entiende:
- `1 sí` · `2 no` · `1 sí, 3 sí`
- `todo sí` / `todo no`
- `1 sí pero hazlo mañana` *(texto libre: lo interpreta y confirma)*

## Confirmación de ejecución (saliente → tu móvil)

```
✅ Hecho:
1️⃣ {título} → {resultado / dónde quedó}
3️⃣ {título} → {resultado}

⏭️ No ejecutadas: 2️⃣ (rechazada)
```

## Reglas de oro del canal
- Solo van por WhatsApp **propuestas y confirmaciones**, nunca datos sensibles de clientes.
- Una respuesta tuya = aprobación válida (equivale a marcar `[x]` en `propuestas/`).
- Si una propuesta toca el exterior (email, CRM), el Becario **vuelve a pedir OK** antes del paso irreversible.
